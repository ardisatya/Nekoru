Scope: local-only U01-L1 learner prototype. Mode: Operate. Audience: Indonesian absolute beginners who need to understand the next learning action without technical vocabulary. The task is to move through onboarding, a short vowel/greeting activity, technical recovery, and an honest session summary. Synthetic demonstration data must stay visibly non-production.

## Direction contract

THESIS: A guided study desk that keeps one learning decision in focus at a time; it refuses the generic dashboard grid and never turns progress into decorative statistics.

OWN-WORLD: Inherit Nekoru's approved warm-neutral, indigo, and sakura system; rounded paper-like learning surfaces, firm 3 px focus, workhorse Plus Jakarta Sans with Noto Sans JP, and restrained cat-ear geometry used only as quiet identity detail.

STORY: The learner understands what will happen, hears or recovers an example safely, answers explicitly, receives supportive feedback, and leaves knowing that completion is not mastery.

FIRST VIEWPORT: A compact session rail sits above one dominant activity canvas. Purpose and technical state occupy a narrow context column on wide screens and collapse above the task on mobile. The primary action remains in normal document flow below the response group.

FORM: Code-led guided practice flow, selected from the repository's exact screen and interaction contracts; concept tournament skipped because P-M1-01–20 and the design system already constrain composition. seed_key: documented-u01-l1-contract.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
